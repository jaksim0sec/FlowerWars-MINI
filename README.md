# 도라가미 · 첫 번째 전장

봇도 플레이어와 같은 배치·이동·경로탐색·충돌 예약·회복·분대 명령을 사용합니다. 빈 전장에서 예비 병력을 직접 배치하며, 봇은 주력 공격·측면 우회·깃발 방어 임무별로 4분대를 편성합니다. 각 완편 소대는 전열·화력·회복 병력을 함께 배치합니다. 적 방패병이 많으면 궁병, 궁병이 많으면 기동병, 기동병이 많으면 방패병을 늘립니다. 처음에는 일부 병력만 배치하고 플레이어의 후속 배치에 맞춰 예비대를 편성하며, 준비 스킵 시 최신 상황으로 남은 병력을 배치합니다. 이미 배치한 병력을 재배치하지 않습니다.

전투 중 궁병·지원대는 실제 살아 있는 전열을 따라가고, 선두는 뒤처진 지원 병력을 기다립니다. 지원대는 같은 소대의 부상 부대를 우선 따라가며, 전열을 잃으면 근처의 생존 전투부대에 합류합니다. 중상 부대는 먼저 철수한 뒤 회복 후 복귀하고, 회복 병력이 전멸한 경우 짧게 재집결한 뒤 임무를 이어갑니다. 깃발 위협은 방어 소대가 우선 처리합니다. 전략 요약은 공유·주기 갱신하고 분대 판단은 나누어 실행하는 규칙 기반 AI입니다.

기본 모드는 **플레이어 vs 봇 깃발 점령전**입니다. 100×100 전장을 중앙선으로 나누고 양쪽에 각각 500명의 예비 병력을 줍니다. 하단 병종을 고른 뒤 파란 진영의 빈 땅을 터치하면 12명씩 즉시 배치됩니다(마지막은 남은 인원). 배치 미리보기는 겹침·장애물·진영 경계를 표시하며, 배치 인원만 예비 병력에서 차감합니다. **지휘 모드**나 분대 목록을 누르면 이동 지휘로 전환합니다. 준비는 5분이며, **준비 스킵 · 전투 시작**으로 즉시 시작할 수도 있습니다. 전투 중에는 적 깃발에 살아 있는 병사가 도달하면 승리합니다(힐러·전사자는 점령 불가, 동시 도달은 무승부). 결과 화면에서 다시 준비할 수 있습니다.

**내 깃발 / 적 깃발**은 시점 이동, **전군 깃발로 진격**은 아군 전체 공격 이동입니다. 봇은 근처 적과 교전하고 일부 부대를 깃발 방어에 남깁니다. 병력·봇 판단·승패 조회는 주기를 분산하며, 축소 화면에서는 기존 캐릭터 그림의 공용 스프라이트를 사용하고 확대하면 개별 애니메이션을 표시합니다. 전체 전장 맞춤과 낮은 배율 확대·축소도 지원합니다. 기존 이동 테스트는 도구 메뉴에 남아 있습니다.

축소 화면의 큰 옅은 A/B 깃발은 각 팀의 실제 병력 중심을 나타냅니다. 승리 목표인 본진 깃발과는 구분됩니다. 전군 진격은 분대 목표를 분산하며, 회복 중인 병사를 경로 대기로 집계하지 않습니다.

대열은 같은 병종끼리 칸을 교환할 수 있습니다. 이미 같은 병종이 서 있는 자리는 도착으로 인정하고, 남은 병력은 총 이동거리가 짧아지는 칸에 배정합니다. 전열은 진행 방향에 맞춰 회전하며 방패·근접병, 원거리·지원병, 후방 중앙 기수와 호위 순서로 구성합니다. 집중 공격 시 일부 근접병은 호위로 남고, 고립된 기수는 실제 전투 병력 후방으로 합류합니다. 호위는 살아 있는 동안 유지해 매 갱신마다 병사가 바뀌지 않습니다.

집중 공격 중에도 지정한 적이 멀리 있으면 사거리 안의 적에게 먼저 반격하고, 원래 지정한 목표 추적은 유지합니다. 기수의 방어 타격은 분대 명령 갱신으로 취소하지 않습니다. 시야가 필요한 원거리 공격은 벽을 피해 사격 위치를 찾습니다. 장애물이 있는 큰 전장에서 분대 이동은 목적지 방향 A* 탐색을 여러 주기에 나눠 처리하며, 전체 맵 거리장을 분대원마다 순차 생성하지 않습니다(기존 탐색 예산·충돌 예약 유지).

지휘 조작: 기본 명령은 이동·집중 공격·우회 공격·정지 한 줄입니다. 방어진·후퇴·공격 이동·사수는 **추가 전술**에서 엽니다. **우회 공격 → 적 분대 선택**은 측면 경유 후 자동으로 집중 공격합니다. 우회 중 적을 터치하거나 집중 공격을 지정해도 경로를 유지하고 공격을 예약합니다. 지면을 목표로 지정하면 우회 이동만 합니다.

소대 제목은 소대 전체 선택, 옆 화살표는 하위 분대 접기·펼치기입니다. 분대를 누르거나 길게 누르면 해당 분대로 선택을 전환합니다. **부대 보기**와 기수 더블 터치는 선택 병력을 확대합니다. 드래그는 화면 이동, 두 손가락은 확대·축소입니다.

새싹힐러는 3칸 내 시야가 열린 부상 아군을 자동으로 24씩 회복합니다(재사용 1.5초). 체력 비율이 낮은 아군을 우선하며 자신도 회복할 수 있습니다. 적을 공격하거나 죽은 병사를 부활시키지 않습니다. 이동 중에는 현재 걸음을 마친 뒤 회복하고 원래 이동을 이어갑니다. 회복은 녹색 + 표시로 확인합니다.

승인된 잔디·흙 입체 타일과 파츠 조립 캐릭터로 만든 2.5D 전장입니다. 별도 패키지 설치·빌드·백엔드 없이 정적 호스팅으로 실행합니다.

Vercel에서는 Framework Preset을 **Other**, Output Directory를 **.**으로 설정하고 Build Command를 비웁니다. 저장소 루트의 `index.html`이 진입점입니다. GitHub Pages 등 일반 정적 호스팅도 사용할 수 있습니다. 모든 게임 이미지가 저장소에 포함되어 외부 이미지 호스트나 API 키가 필요하지 않습니다. 로컬 미리보기는 기존 정적 파일 미리보기 도구에서 저장소 루트를 열면 됩니다. ES 모듈과 이미지 설정을 불러오므로 `file://`로 직접 열지는 않습니다.

플레이 방법:

- **⚙ 디버그 → 기존 하단 조작 바 표시**를 켠 뒤 **소환**을 누르고 빈칸을 선택합니다. 시작 시 개나리 방패병와 개나리소환사가 배치됩니다. 캐릭터 선택으로 소환할 종류를 바꿀 수 있습니다. 기존 개나리용사·새싹힐러는 숨김 상태로 보관하며 현재 목록에는 새 캐릭터 6종을 표시합니다.
- 용사를 선택하고 빈칸을 누르면 다른 용사를 피해 한 칸씩 걸어갑니다.
- **공격**을 누른 뒤 다른 용사를 선택합니다. 멀리 있으면 인접한 칸까지 이동한 뒤 검을 휘두릅니다. 명중 시 체력이 25 감소하며, 체력 0이면 파츠가 무너지는 연출 뒤 퇴장합니다. 선택한 용사의 정확한 체력과 건강·부상·빈사 상태는 하단에서 확인합니다.
- 마우스/한 손가락 드래그로 보드 이동, 휠/두 손가락 핀치로 확대·축소합니다. 오른쪽 버튼으로 확대, 축소, 전장 맞춤을 할 수도 있습니다.
- 용사 선택을 해제한 뒤 빈 타일을 선택하면 해당 칸의 잔디·흙을 바꿀 수 있습니다. 보드 바깥이나 `Esc`로 선택을 해제합니다.
- 초기화는 지형과 용사, 진행 중인 동작을 처음 상태로 되돌립니다.
- 키보드: 전장에 포커스 후 방향키로 칸 탐색, `Enter`로 선택, `S`로 소환 모드, `A`로 공격 모드, `Esc`로 해제.

구성:

- `src/model.mjs`: 타일, 점유, 경로 탐색, 이동 보간, 명중 타이밍. 브라우저와 독립된 모델입니다.
- `src/combat.mjs`: 테스트 진영·공격 범위·주변 적 조회·공속과 공격 시간 변환.
- `src/navigation.mjs`: 공유 거리장, 한 칸 예약, 경로 재사용·대기·우회와 탐색 예산.
- `src/movement-scenarios.mjs`: 선택적으로 사용하는 재현용 동시 이동 배치.
- `src/render.mjs`: 보드 타일 보정·깊이 정렬 및 캐릭터 엔진 호출.
- `src/characters/`: 보드와 독립된 인스턴스·장비·리그·애니메이션·카탈로그. `characters.html`에서 같은 엔진으로 미리보기합니다.
- 자세한 API와 확장 방법은 `docs/character-engine.md`를 참고하세요.
- `src/app.mjs`: 포인터·터치·키보드 입력, 카메라, 선택과 최소 UI.
- `assets/`: 기존 승인 이미지와 리그 메타데이터. 검은 손과 독립된 이미지로 유지합니다.
- `legacy/index.html`: 이전 게임 원본 보관.

직접 파츠를 조정하려면 캐릭터 연구실의 **리그 직접 조정 · JSON 내보내기**를 엽니다. `rig-editor.html`에서 순서대로 캐릭터를 편집하고 개별·전체 JSON을 저장할 수 있습니다. 사용법과 적용 방법은 `docs/rig-editor.md`를 참고하세요.

브라우저 검증은 기본적으로 `/usr/bin/chromium`을 사용합니다. 다른 설치 경로는 `CHROMIUM`, 호스팅 주소는 `BASE_URL` 환경 변수로 지정할 수 있습니다. 데스크톱과 모바일 터치에서 소환·선택·실제 보행·공격·피격·드래그·핀치·초기화, 지형 변경, 이미지 누락 안내를 검사합니다. 모바일 레이아웃 검증은 다섯 화면 크기에서 확대·이동해도 전장이 헤더·조작부 영역을 침범하지 않는지, 화면 높이가 바뀌어도 배치가 유지되는지 검사합니다.

이번 버전은 조작 시연용입니다. 서로 다른 용사는 동시에 이동·공격할 수 있으며, 각 개체는 충돌을 피하며 대기·우회합니다. 동작 중인 해당 용사는 동작을 마친 후 새 명령을 받습니다. 오른쪽 위 **이동 테스트**에서 교차·병목·장애물 상황을 최대 1,000개체로 배치해 검증할 수 있습니다. 알고리즘·확장 API·측정 한계는 `docs/concurrent-navigation.md`를 참고하세요. 체력·부상·빈사·사망 연출을 지원하며, 테스트 배치에서는 A/B 진영이 등록된 사거리 안의 적과 자동 교전합니다. 시드·좌우 교환, 병종별 이동 성격과 원거리 탐색은 `docs/tactical-foundation.md`를 참고하세요. 기본 전장은 기존 중립 수동 시연을 유지하며 승패 판정·자동 추격은 없습니다. 임시 병종 능력치와 조작법은 `docs/test-combat.md`를 참고하세요. 방향 전환은 제공된 파츠의 좌우 반전을 사용합니다. 별도의 후면 원화는 현재 저장소에 없습니다. 화면을 구성하는 모든 필수 이미지가 실제로 존재하며, 누락 시 파일 경로를 안내하고 대체 디자인을 사용하지 않습니다.

지형과 그림자는 화면 크기의 캐시로 그리며 카메라·지형이 바뀔 때만 다시 만듭니다. 화면 밖 타일은 재생성 대상에서도 제외합니다. 측정 결과와 재현 방법은 `docs/render-performance.md`를 참고하세요.

전장은 화면 전체를 사용하며 테스트 조작부만 작게 겹쳐 표시합니다. 화면 밖 캐릭터는 파츠 계산과 정렬에서 제외하고 대기·보행 포즈는 화면 배율에 따라 15~30Hz로 재사용합니다. 보이는 대기 모션은 30Hz로 그리며 변화 없는 빈 화면은 다시 그리지 않습니다. 카메라 조작 중에는 지형 캐시의 여유 영역을 재사용하고 조작 종료 후 원래 품질로 갱신합니다.

오프라인 실행: HTTPS 또는 localhost에서 처음 한 번 접속해 서비스워커 캐시 설치가 끝나면 전장·캐릭터 연구실·리그 편집기를 네트워크 없이 다시 열 수 있습니다. `manifest.json`은 홈 화면 설치 정보를 제공합니다. 코드·리그·어셋·HTML 변경 후에는 **`python3 scripts/build_offline.py`로 `sw.js`를 재생성하고 함께 커밋**합니다. 새 버전 설치 후 기존 앱 탭을 모두 닫고 다시 열면 갱신됩니다. 브라우저 저장공간을 지우면 온라인에서 다시 캐시해야 합니다. 검증: `BASE_URL=http://127.0.0.1:8019 python3 tests/offline-browser.py`.

소대/분대 묶음 생성과 배치: 상단 **⚙ 디버그 → 소대/분대 배치**에서 설정 후 앞줄 기준 칸을 선택합니다. 데이터 형식과 API는 `docs/unit-groups.md`, 검증은 `tests/groups.test.mjs`와 `tests/groups-browser.py`를 참고하세요.

승리 방향 편향의 1,000개 시드 재검증과 활 발사 모션 변경은 `docs/win-bias-and-bow.md`를 참고하세요.

**전장 설정**에서 가로/세로4~256칸을 변경할 수 있습니다. 기존 병력·진행 중인 이동·기존 영역의 지형을 유지하며 병력이나 이동 목표가 잘리는 축소는 거절합니다. **전체 공격 활성**은 현재 생존 유닛의 자동 공격을 켜고, 무진영 유닛만 A/B로 균형 배정합니다. **공격 중지**는 새 자동 공격을 멈추며 이미 시작한 타격은 마무리합니다. 개나리 보병(기존 개나리 기사)의 권장 무기는 기본 검입니다.


분대 지휘: 기수 초상 또는 전장의 병사를 선택하면 하단에 **선택 분대 수·생존 병력·현재 명령·실행 상태**와 빠른 명령 바가 표시됩니다. 선택은 명령 후에도 유지되며 선택한 모든 병력에 표시가 남습니다.

- **여러 분대:** PC는 Shift/Ctrl/Cmd를 누르고 추가 선택, 터치는 **＋ 추가 선택**을 누른 뒤 부대를 한 번 선택합니다. 추가 선택은 즉시 해제되며, 명령 후 다른 부대를 누르면 해당 부대만 선택됩니다. 이미 선택한 분대를 추가 선택하면 해당 분대만 제외합니다. 적군과 아군은 함께 선택할 수 없습니다.
- **소대 선택:** 선택한 분대가 속한 소대의 분대를 한 번에 선택합니다. 여러 소대의 분대를 추가 선택한 뒤 누르면 각각의 소대를 함께 선택합니다.
- **명령 → 목표:** 이동·공격 이동·집중 공격·우회 기동·방어진 구축·후퇴는 버튼을 누른 뒤 전장에서 목표를 지정합니다. 목표 지정 안내에 수신 분대 수가 표시됩니다. 취소와 Esc는 병력 선택을 유지합니다.
- **빠른 명령:** PC 우클릭은 지면 이동, 적 병력 집중 공격입니다. 버튼을 선택한 직후에도 M 이동, A 공격 이동, R 후퇴, H 현 위치 사수, X 정지를 사용할 수 있습니다. 왼쪽/가운데/오른쪽 드래그는 카메라 이동이며 명령을 내리지 않습니다. 두 손가락 핀치는 확대·축소입니다.
- **명령 구분:** 이동·후퇴는 교전보다 이동을 우선합니다. 공격 이동은 적과 교전하며 전진합니다. 우회 기동은 측면 집결 → 측면 전진 → 목표 접근 순서입니다. 방어진 구축은 방패병을 앞에 배치하고 기수·원거리 병력을 뒤에 둔 전열을 만든 뒤 사수합니다. 현 위치 사수는 재배치 없이 교전하며, 정지는 이동·공격을 멈춥니다.
- **태세·진형:** 별도 옵션에서 선택 부대 전체에 적용합니다. 기수 집결·아군 추종·사격진 구축도 이곳에 있습니다. 중복 특수 명령 버튼은 제거했습니다.
- **명령 확인:** 선택 부대의 목표·우회 경유점·최종 배치 위치를 전장에 표시합니다. 여러 분대는 서로 다른 배치 칸을 사용하며, 모서리에서는 전체 진형이 들어가도록 안쪽에 배치합니다.

새 분대 명령은 이전 이동·공격 의도를 즉시 교체합니다. 이미 시작한 한 걸음은 예약된 칸까지 마친 뒤 새 방향으로 이동하며 순간 이동하지 않습니다. 분대 명령은 0.1초마다 갱신하고, 피격을 받아도 생존한 진영 병력은 명령을 유지합니다. 일반 개별 중립 시연은 기존 동작을 유지합니다.

길찾기는 기존 한 칸 예약과 주기당 2,048회 탐색 예산을 유지하며, 작은 우회 탐색이 실패하면 여러 주기에 걸쳐 넓은 우회로를 찾습니다. 완전히 막힌 목표나 매우 큰 밀집 구역은 대기할 수 있습니다. 우회는 측면 경유 전술이며 적의 모든 사거리·피해량을 예측하는 전투 AI는 아닙니다. 현재 표시선은 명령의 목표와 경유점을 나타내며 장애물을 반영한 완성 경로 예측은 아닙니다.

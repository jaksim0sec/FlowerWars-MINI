# 소대/분대 데이터와 묶음 배치

좌측 **소대/분대 배치**에서 단위·병력 수·이름·진영을 선택하고 **묶음 배치**를 누른 뒤 전장의 앞줄 기준 칸을 선택합니다. 병력 전체가 들어갈 빈 공간이 없으면 일부만 생성하지 않고 배치 전체를 거절합니다. 기존 개별 소환·선택·이동도 유지합니다.

`src/unit-groups.mjs`의 `createFormationGroup(count,kind,name)`은 `doragami-unit-group` v1 JSON 템플릿을 만듭니다. `kind`는 `squad`(분대)/`platoon`(소대), 각 `members`는 캐릭터 ID·역할·기준점 상대 좌표·장비/능력치 설정을 가집니다. 템플릿은 직렬화하고 재사용할 수 있으며 중첩 설정까지 독립 복사합니다.

`placeGroup(board,template,anchor,options)`는 생성 전에 전체 좌표·점유·예약·장애물을 확인합니다. 성공하면 그룹의 이름·진영·기준점·템플릿·`memberIds`를 반환하고 개별 유닛에 `groupId`/`memberIndex`를 붙입니다. `groupsFor(board)`로 그룹 Map을 조회합니다. 전장 초기화 시 그룹도 새로 시작합니다. 전투 중 손실은 유닛의 기존 체력/사망 처리에 따르며 그룹의 원래 편성 데이터는 남습니다.

양군 전투 진형 테스트의 기존 A/B 소대 등록은 유지됩니다. 각 소대 아래 최대 12명의 분대가 생성되며, 분대마다 골든개나리병(기수)이 지휘관입니다. 12명마다 기수가 충분하도록 테스트 편성을 자동 조정합니다. `squadsFor(board)`와 `squadOf(board,unit)`으로 분대 정보를 조회합니다. 기수가 사망하면 새 명령을 받지 못합니다.

일반 묶음 배치에서 분대 유형(혼성/돌격/철벽/궁병/기동/지원)을 고릅니다. 개별 유닛을 선택하면 **분대 명령**에서 위치 지정 이동·진격·사수·집중 공격·집결·후퇴·추종·대기와 태세 및 진형을 설정합니다. 목표 지정 명령은 실행 후 전장 타일/상대 분대를 선택합니다. 분대별 특수 명령은 각 기본 명령과 진형의 조합으로 동작하며, 치유/소환/방어력 버프는 새로 추가하지 않습니다. `src/squad-orders.mjs`가 기존 `Board.move/attack/batchCommands`만 호출하며, 0.5초 간격으로 미발령/추종 명령을 정리합니다.

검증: `tests/groups.test.mjs`, `tests/groups-browser.py`. 이름 있는 분대의 일괄 생성, 실패 시 개체/ID 보존, 좌우 방향, 초기화, 템플릿 독립성, 기존 테스트 병력 그룹 등록을 검사합니다.

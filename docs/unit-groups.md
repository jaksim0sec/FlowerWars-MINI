# 소대/분대 데이터와 묶음 배치

상단 **⚙ 디버그 → 소대/분대 배치**에서 단위·병력 수·이름·진영을 선택하고 **묶음 배치**를 누른 뒤 전장의 앞줄 기준 칸을 선택합니다. 병력 전체가 들어갈 빈 공간이 없으면 일부만 생성하지 않고 배치 전체를 거절합니다. 기존 개별 소환·선택·이동도 유지합니다.

`src/unit-groups.mjs`의 `createFormationGroup(count,kind,name)`은 `doragami-unit-group` v1 JSON 템플릿을 만듭니다. `kind`는 `squad`(분대)/`platoon`(소대), 각 `members`는 캐릭터 ID·역할·기준점 상대 좌표·장비/능력치 설정을 가집니다. 템플릿은 직렬화하고 재사용할 수 있으며 중첩 설정까지 독립 복사합니다.

`placeGroup(board,template,anchor,options)`는 생성 전에 전체 좌표·점유·예약·장애물을 확인합니다. 성공하면 그룹의 이름·진영·기준점·템플릿·`memberIds`를 반환하고 개별 유닛에 `groupId`/`memberIndex`를 붙입니다. `groupsFor(board)`로 그룹 Map을 조회합니다. 전장 초기화 시 그룹도 새로 시작합니다. 전투 중 손실은 유닛의 기존 체력/사망 처리에 따르며 그룹의 원래 편성 데이터는 남습니다.

기본 **양군 전투 편성**은 A/B 각각 **대대 → 소대(최대 4분대) → 분대(최대 12명)**로 묶입니다. 분대는 돌격대·철벽대·궁병대·기동대·혼성대·지원대로 구분해 실제 캐릭터 비율과 전열/후열 위치를 다르게 배치합니다. 분대마다 골든개나리병(기수)이 지휘관이며, 좌우 진영은 대칭으로 배치됩니다. 기존 교차·병목·군중 등의 순수 이동 진단 배치는 변경하지 않습니다. `squadsFor(board)`와 `squadOf(board,unit)`으로 분대 정보를 조회합니다. 기수가 전사하면 살아 있는 분대원 중 한 명이 임시 지휘관을 맡으며, 이동·교전·추종 명령은 계속 작동합니다. 마지막 생존자까지 전사한 분대만 새 명령을 받을 수 없습니다.

일반 묶음 배치에서 분대 유형(혼성/돌격/철벽/궁병/기동/지원)을 고릅니다. 개별 유닛을 선택하면 **분대 명령**에서 위치 지정 이동·진격·사수·집중 공격·집결·후퇴·추종·대기와 태세 및 진형을 설정합니다. 목표 지정 명령은 실행 후 전장 타일/상대 분대를 선택합니다. 분대별 특수 명령은 각 기본 명령과 진형의 조합으로 동작하며, 치유/소환/방어력 버프는 새로 추가하지 않습니다. `src/squad-orders.mjs`가 기존 `Board.move/attack/batchCommands`만 호출하며, 0.5초 간격으로 미발령/추종 명령을 정리합니다.

검증: `tests/groups.test.mjs`, `tests/groups-browser.py`. 이름 있는 분대의 일괄 생성, 실패 시 개체/ID 보존, 좌우 방향, 초기화, 템플릿 독립성, 기존 테스트 병력 그룹 등록을 검사합니다.


## 지휘 UI (2026-10-26)

기존 하단 개별 조작 바는 초기 화면에서 숨김 처리하며, **⚙ 디버그 → 기존 하단 조작 바 표시**로 다시 활성화할 수 있습니다. 이동 테스트·전장 설정도 동일한 디버그 메뉴에 들어 있습니다.

분대가 존재할 때 PC 오른쪽, 모바일 하단에 분대 목록이 표시됩니다. 모든 분대 항목에는 등록된 골든개나리병 기수의 실제 캐릭터 리그로 렌더링한 얼굴 초상, A/B 팀, 살아 있는 인원이 나타납니다. 기수 얼굴 아이콘을 누르면 해당 분대의 명령창이 즉시 열립니다. 같은 아이콘을 다시 눌러도 명령창은 유지되며, ×·바깥 화면·Esc로 닫습니다. **명령 아이콘을 누르면 즉시 실행**하며 목표가 필요한 이동/진격/집중 공격/후퇴/추종은 바로 전장 목표 선택 모드로 전환합니다. 태세·진형도 아이콘 터치 즉시 적용됩니다. 목표 선택 도중에는 취소 버튼이 표시됩니다. 지휘관 전사 시 명령은 비활성화되며 분대 목록에는 남습니다. 목록의 DOM/초상은 캐시하여 1,000명 전투에서 매 프레임 재생성하지 않습니다.

디버그 메뉴와 분대 명령창은 높이를 제한한 스크롤 가능한 소형 패널이므로 전장 전체를 가리지 않습니다.


분대 목록의 기존 카드·테두리·배경 패널과 제목줄을 제거하고, 기수 얼굴과 작은 팀·분대명·잔존 인원만 직접 표시합니다. PC는 오른쪽 세로, 모바일은 하단 가로 스트립입니다. 명령창도 약 230px 폭의 고밀도 아이콘 팔레트로 축소했습니다. CSS `[hidden]`이 레이아웃의 `display:flex`에 덮이지 않도록 별도 보장합니다.


## 자동 교전과 기수 생존 (2026-10-26)

기본 분대 명령은 **이동·진격·후퇴·사수·대기 중에도** 기존 자동 근접 교전을 끄지 않습니다. 접근한 적을 기존 사거리 안에서 스스로 공격하며, 사용자가 디버그에서 명시적으로 자동 공격을 꺼둔 경우에만 그 설정을 존중합니다. 집중 공격의 표적 지시는 병사에게 우선 적용하되 기수는 적진 추적에 참가하지 않고 근접 위협만 자동 대응합니다.

기수는 명령 수행 시 다른 병사보다 후방의 목표 칸을 받으며, 기본 **대대 전투 편성**에서도 모든 분대원 뒤에 배치하고 적진을 관통하는 자동 행군을 시키지 않습니다. 기수 전사 시 남은 분대원이 ID 순으로 임시 지휘관에 승계하며, 임시 지휘관이 다시 전사하면 다음 생존자가 맡습니다. 이때 기수가 부활하거나 능력치 버프가 생기지 않습니다. 모든 병력이 전멸한 경우에만 분대 명령을 거절합니다. 살아 있는 인원이 1명뿐이어도 집중 공격 명령을 수행할 수 있습니다.

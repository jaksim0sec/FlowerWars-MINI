# 승리 편향 재검증과 활 발사 개선

이전 검증은 진영 이름/좌우 반전의 일부 시드만 확인했고, 여러 시드의 완전 승리와 생존 우세 분포를 구분하지 못했습니다. 이번에는 실제 64인 편성, 병종 능력치·낙엽병 변형·무기 이동 배율을 적용해 1,000개 시드를 각120초씩 실행하고 같은 개체 ID를 유지한 채 물리적 위치만 교환했습니다.

원인은 동서남북 고정 순서의 국소 우회였습니다. 상대 진영은 반대 방향으로 전진하므로 같은 빈칸 배치에서도 우회 성공/대기 시점이 달라졌습니다. 목적지 진행 방향을 기준으로 동일한 이웃 탐색 순서를 사용하도록 수정했습니다. 목적지 열에 도달해도 기존 접근 방향을 유지합니다. 또 거리가 약9e-16칸 차이로 달라져 동률 우선순위를 건너뛰던 사례를 재현해, 공격 대상 점수를 1e-9칸 정밀도로 비교하도록 했습니다.

| 1,000개 시드, 완전 전멸 승리 | 원래 위치 | 양측 위치 교환 |
|---|---:|---:|
| 수정 전 | A30 / B61 | A63 / B16 |
| 수정 후 | A73 / B55 | A73 / B55 |

수정 후 1,000개 시드 모두 위치 교환 전후의 생존 수·체력·승자·우세 진영이 일치했습니다. 명중 합계도 양쪽346,063회로 일치합니다. 총 잔존 병력은 A3,757/B3,881입니다. 872개 시드는 양측이 살아 있는 미결 상태이며, 현재의 근접 탐색/목표 이동은 전장 전체 자동 추격을 하지 않기 때문입니다. 미결을 승리로 집계하지 않았습니다. 단일 전투의 몰살/일방적 생존 결과를 강제로 동률로 만드는 능력치 보정은 없습니다.

재현: `node scripts/formation-bias-benchmark.mjs --seeds=1000 --seconds=120`. 회귀: `tests/formation-bias.test.mjs`의 실제 프로필·위치 교환 검증. 이 수치는 모델 시뮬레이션이며 브라우저 FPS 측정은 아닙니다.

활은 공통 검 휘두르기 채널을 사용하던 원인을 제거하고 장비/리그 데이터로 조준→시위 당기기→발사→복귀를 구성합니다. 시위와 화살을 표시하며 손바닥 연결을 유지합니다. 발사는 기존 정규화 공격 시간0.30초와 맞추고, 기존 공속에 따른 시간 배율·피해 처리 방식은 유지합니다. 왼손/오른손과 양쪽 바라보는 방향에서 발사 방향을 검증합니다. 새 캐릭터 전용 ID 분기를 엔진에 넣지 않습니다.

후속 방향 수정: 장착 손에 따라 캐릭터 전체에 반전 배율을 적용하던 방식은 제거합니다. 화살의 세계 방향만 검사해서는 몸이 등을 돌린 것을 잡지 못했습니다. 캐릭터의 바라보는 방향은 장비와 독립적으로 유지하고 활/팔 자세를 보정합니다. 낙옆궁수의 기본 활은 원화의 전방 팔인 왼손에 장착하며 오른손 장착도 몸 방향을 바꾸지 않습니다. 검증은 발사 후 화살뿐 아니라 장전 화살·시위 당기는 손·몸의 반전 행렬까지 포함합니다.

# 체력과 장난감 사망 연출

체력은 생성 인스턴스의 `health`에 보관합니다. 기본 최대 체력은 100이며 캐릭터 등록의 `maxHealth`로 변경할 수 있습니다. 보드 유닛은 이 객체를 공유하고 공격 명중 시 기본 피해 25를 한 번 적용합니다. 60% 이하는 부상, 30% 이하는 빈사입니다. 정확한 수치는 선택한 캐릭터에만 표시하며 체력바·체력 마커는 추가하지 않습니다.

`advanceHealth(health, dt)`는 자세의 부상/빈사 강도를 지수 보간합니다. 머리와 어깨 처짐, 느린 시각 리듬, 불안정한 상체 흔들림만 적용합니다. 이동 시간과 공격력, 공격 명중 타이밍에는 변화가 없습니다. 회복은 `Board.heal(id, amount)`로 지원하고 최대 체력에서 제한하며, 사망한 캐릭터를 되살리지는 않습니다. 별도의 회복 버튼이나 자동 회복 규칙은 추가하지 않았습니다.

체력 0은 즉시 `death` 상태로 전환합니다. 선택·공격·경로 점유 대상에서는 바로 제외하되 렌더링 객체는 1.7초 유지합니다. 처음에는 타격 방향으로 휘청이고 기울며, 약 0.3초부터 장비·머리장식·팔·다리가 파츠별 시간차로 분리됩니다. 분리된 각 파츠는 자체 피벗으로 회전하고 중력 곡선과 감쇠 바운스로 착지합니다. 실제 회전된 이미지 경계를 사용해 바닥 아래로 떨어지지 않게 하고 마지막 0.35초에 자연스럽게 사라집니다. 새 이미지나 비율 변경 없이 현재 파츠와 장비를 그대로 사용합니다. 초기화는 사망 중인 객체와 잔여 효과까지 제거합니다.

리그의 선택적 `vitality`에서 `headDroop`(기본 .07 rad), `criticalSway`(.065 rad), `fallAngle`(.62 rad), `scatter`(22 리그 단위), `parts.<파츠 이름>.delay`(초)를 바꿀 수 있습니다. 설정이 없으면 공통 기본값으로 작동합니다. 보드와 독립된 `layoutCharacter`/`drawCharacter`에서도 같은 연출을 사용할 수 있습니다. 외부 UI는 `advanceHealth`를 호출하고 사망 시 `animation.state='death'`, `elapsed`, `deathDirection`을 제공합니다.

검증은 `tests/health.test.mjs`와 `tests/health-browser.py`에 있으며, 기존 비율·손잡이·레이어 테스트도 유지합니다. 실제 6종 엔진 렌더링은 [연출 미리보기](health-death-preview.gif)에서 확인할 수 있습니다.

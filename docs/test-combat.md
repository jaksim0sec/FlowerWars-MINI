# A/B 테스트 교전

기본 테스트는 **이동 테스트 → 양군 전투 진형 → 배치 → 동시 이동**입니다. 64개체 기준 각 진영은 전방 방패병 5, 중앙 깃발병 1, 정찰병 22, 후방 궁수 2·낙엽병 2로 대칭 배치합니다. 낙엽병은 갈색 잎의 궁수 외형에서 활·등/허리 장비를 빼고 검을 장착한 임시 보병(체력110/공격26/0.85초)입니다. 비율·자리·테스트 역할은 `src/test-formation.mjs`에서 관리하며 기존 리그는 그대로 유지합니다. 기존 **A/B 근접 교전** 등 진단용 배치도 선택할 수 있습니다. **A/B 교전**은 기본 체크이며 배치 설정에 적용합니다. 체크를 끄고 다시 배치하면 기존 순수 이동 테스트를 유지합니다. 배치만으로 전투를 시작하지 않습니다. 진영은 A/파랑, B/주황의 발밑 테두리로 구분하며 선택 시 진영·정확한 체력·공격력·공속을 표시합니다. 상시 체력바는 없습니다.

현재 여섯 캐릭터는 모두 체스 킹과 같은 **주변 8칸, 거리 1**의 근접 공격을 사용합니다. 같은 진영·중립 캐릭터는 자동 공격하지 않습니다. 이동 중에는 예약한 한 걸음을 끝낸 뒤 범위 안 적에게 공격하고, 적이 죽거나 범위 밖으로 나가면 원래 목적지로 이동을 이어갑니다. 대기 중에도 같은 판정을 합니다. 먼 적을 자동 추적하지 않습니다. 공격 시작과 명중 시 실제 보간 위치의 범위를 확인하므로 달아난 적에게 원격 명중하지 않습니다.

자동 판정은 기존 이동 결정 주기(약 0.12초)를 사용합니다. 각 준비된 개체는 자기 주변 최대 9개 칸의 현재 점유/이동 예약을 조회합니다. 중복 대상을 제거하고 가까운 적, 동거리면 ID 순으로 고릅니다. 모든 적과 거리를 비교하는 N² 탐색은 없습니다. 공격 동작 중·피격 회복 중·한 걸음 진행 중에는 새 자동 공격을 시작하지 않습니다.

공격 동작 길이와 명중 시점은 공속에 맞춰 늘이거나 줄이며 파츠·무기 리그는 그대로 사용합니다. 같은 시뮬레이션 구간에서 명중이 확정된 공격은 피해 적용 전에 모아 처리합니다. 서로 치명타를 주고받을 수 있습니다. 살아 있는 개체의 이미 시작한 공격은 피격으로 취소하지 않아 느린 병종이 빠른 병종에게 영구적으로 공격을 봉쇄당하지 않습니다. 체력·부상 자세·타격 효과는 적용합니다. 자동 이동 명령은 피격 후에도 유지하며, 사망 시 명령·점유·예약을 즉시 해제하고 기존 장난감 사망 연출을 마칩니다.

## 임시 능력치

`assets/characters.json`의 각 캐릭터 `testCombat`에 보관합니다. 캐릭터 엔진에 병종 ID 분기는 없습니다. 공속은 아래 공격 주기의 역수이며 실제 개시 시점에는 약 0.12초의 판정 주기 차이가 생길 수 있습니다.

| 병종 | 체력 | 공격력 | 공격 주기 | 공속(회/초) |
|---|---:|---:|---:|---:|
| 개나리 방패병 | 180 | 38 | 1.25초 | 0.80 |
| 개나리소환사 | 85 | 24 | 1.10초 | 0.91 |
| 골든개나리병 | 130 | 26 | 0.95초 | 1.05 |
| 새싹힐러 | 90 | 42 | 1.35초 | 0.74 |
| 낙옆궁수 | 80 | 22 | 0.70초 | 1.43 |
| 개나리 기사 | 75 | 14 | 0.45초 | 2.22 |

교전 배치에서는 같은 병종을 A/B에 한 명씩 짝지어 등록합니다. 기본 전장·일반 소환·캐릭터 미리보기는 기존 중립 수동 시연을 유지합니다(기본 체력 100, 피해 25, 공격 동작 0.65초). **기본 전장**이나 기존 초기화로 테스트 병력을 제거합니다. 소환 UI의 일반 소환에는 임시 A/B 설정을 강제하지 않습니다.

## 데이터/API

```js
const unit = board.spawn(x, y, character, {
  team: 'A',
  autoCombat: true,
  stats: {maxHealth: 180, damage: 38, attackPeriod: 1.25, range: 1, rangeShape: 'king'},
});
```

`unit.combat`는 독립된 공격 주기·범위·모양·다음 공격 가능 시각을 보관합니다. `unit.strike`는 진행 중인 공격입니다. 범위·모양을 향후 캐릭터별로 변경할 수 있으며 지금은 모두 같은 테스트 범위입니다. 장애물 시야 판정, 투사체, 방어력, 버프, 자동 추격·승패 판정은 추가하지 않습니다. 보드와 독립된 렌더링은 공격 시간만 전달받습니다.

동일한 목적지를 지정해도 같은 칸을 공유하지 않습니다. 먼저 도착한 개체가 점유하며 나머지는 대기·우회합니다. 목적지를 주변 칸으로 자동 분산하지 않습니다. A/B 교전이 켜져 있으면 가까운 적과 먼저 교전합니다.

화면 밖에서도 체력·공격·이동·사망 처리는 진행합니다. 화면 밖 교전과 타격 효과만 있을 때 빈 화면을 매 프레임 다시 그리지 않습니다. 움직이는 개체가 화면에 진입하면 그리기를 재개합니다.

## 검증

```sh
node --test --test-isolation=none tests/*.test.mjs
node scripts/benchmark_combat.mjs
BASE_URL=http://127.0.0.1:8019 python3 tests/combat-browser.py
```

개발 환경의 1,000개체 근접 교전 모델을 50Hz·12초 동안 진행한 측정: update p95 약 0.152ms, 공격·명중 각 4,500회, 중복 점유/예약 0. 화면 그리기를 포함한 브라우저 FPS나 모바일 성능 수치는 아닙니다. 노드 테스트는 범위·진영·공속·동시 치명타·이동 복귀·같은 목적지·화면과 독립된 주변 조회 한도를 검증합니다. 브라우저는 시작 전 대기·선택 수치·A/B 교전·교전 비활성·화면 밖 사망/그리기 중단·모바일·초기화를 검증합니다.

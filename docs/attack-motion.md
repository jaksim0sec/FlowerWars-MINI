# 공격 모션

사용자 원본: https://github.com/jaksim0sec/mnifinasntmnt/blob/main/y_common.css

`attack`, `attackBody`, `attackHead`의 준비(55%) → 타격(75%) → 복귀 흐름을 사용한다. 원본의 타격 시점을 실제 전투의 정규화된 충돌 시점 0.30초에 맞춰 준비 0.22초·타격 0.30초·복귀 0.65초로 변환한다. 목과 손목 관절은 고정하며 상체 이동·기울임과 머리 회전으로 무게를 표현한다. 활·깃발·지팡이·창은 각각의 조준·시전·찌르기 자세를 유지한다.

기본 분대는 24명에 기수 1명이다. 대장을 제거하는 대체 편성은 쓰지 않는다. 24명 편성은 봇 작전당 2개 분대로 묶어 약 48명의 기존 작전 규모를 유지하며, 작은 사용자 편성은 기존 4개 분대 작전을 지원한다.

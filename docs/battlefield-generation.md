# Natural tactical terrain

The generator now constructs an irregular, elongated landmass within the 144×112 simulation bounds. The unused exterior is genuinely absent land: it is not drawn as grass or water, cannot be entered or deployed on, and cannot be painted into walkable ground. The terrain cache draws cliff layers only at the actual land edge. Territory overlays are clipped to that outline.

The spaces have distinct functions: deployment grounds at either end, restricted main exits, a broader central fighting area, and smaller winding routes outside the separating lakes. Gaps between the home headlands and longer lake bodies allow interception behind the front; gaps between the longer bodies lead into the side of the central fight.

Independent smoothly interpolated shorelines determine the land contour. Lake banks grow between the space reserved for the main force and the space reserved for the outside flank. Their widths, bends, tips and separation vary by seed. Narrow headlands and longer separating bodies use different proportions. The map is no longer assembled from mirrored crescent polygons, rectangular perimeter ponds or road lines cut through water. There is no forced rotational symmetry. Both sides must instead satisfy the same connectivity, gate-width and flank-width constraints.

Generation runs once. Rendering retains the global 5×2 texture phase, separate material seams, viewport terrain cache and single cached image draw on unchanged frames. Terrain identity and void occupancy are shared by placement and navigation. Bot operation placement may search the full board extent when its preferred point lies outside the new coastline; complete operation footprints remain required.

Validation: 32 seeds pass the focused generation constraints, including three distinct openings at each main gate (central 13–22 tiles in the sampled seeds, side openings 4–10), a broad grass fighting area, connected protected routes, and distinct asymmetric layouts. All 350 bot troops deploy for each seed. A separate 100-seed connectivity check found no isolated walkable islands. Nine focused terrain tests pass. Real Chromium rendering through intercepted local file requests reports no page errors; unchanged terrain retains one cache build across repeated frames.

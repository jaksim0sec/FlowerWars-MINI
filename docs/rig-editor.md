# 직접 리그 조정

캐릭터 연구실 상단의 **리그 직접 조정 · JSON 내보내기**로 열거나 `rig-editor.html`에 접속합니다.

1. 캐릭터와 조정 대상을 선택합니다. 얼굴과 머리장식을 함께 움직이려면 **머리 전체**를 선택합니다.
2. 화면에서 드래그하거나 숫자로 위치·크기·각도·회전축을 조정합니다. 회전축은 주황색 십자, 선택 영역은 파란색으로 표시합니다. 파츠의 회전축은 파츠 안 픽셀 좌표이며 묶음의 회전축은 리그 좌표입니다.
3. **가로세로 비율 고정**을 해제하면 너비와 높이를 각각 조정할 수 있습니다. **회전축만 옮길 때 그림 위치 유지**를 켜면 축을 옮겨도 현재 그림은 제자리에 유지됩니다.
4. 레이어 대상을 고르고 앞/뒤 버튼으로 같은 묶음 안의 그리는 순서를 바꿉니다. 서로 다른 묶음 전체의 순서를 바꾸려면 그 묶음을 선택합니다.
5. 대기·이동·공격·피격, 방향, 시간 슬라이더로 확인합니다. 재생 중에도 값이 반영되며 드래그를 시작하면 일시정지합니다. 장비를 해제하거나 손별/양손 잡기로 연결도 확인할 수 있습니다.
6. **조정 완료 · 다음**으로 순서대로 진행합니다. 마지막 캐릭터에서는 완료 표시만 합니다. 이전·다음이나 목록으로 자유롭게 돌아갈 수 있습니다.
7. **이 캐릭터 JSON 내보내기** 또는 **전체 JSON 내보내기**로 저장합니다. 전체 파일 하나를 전달하면 됩니다. 파일을 다시 불러와 이어서 편집할 수도 있습니다.

임시 저장은 해당 브라우저의 localStorage를 사용합니다. 마지막 캐릭터, 완료 표시, 리그, 공통 장비 설정과 미리보기 장착/방향/동작이 복원됩니다. 브라우저 저장소를 지우거나 다른 기기를 쓰면 임시 저장을 공유하지 않으므로 JSON 파일을 별도로 보관합니다. 레퍼런스 이미지는 비교용으로만 표시하며 업로드하거나 JSON에 포함하지 않습니다.

키보드: 캔버스에 포커스하고 방향키로 1단위, Shift+방향키로 10단위 이동합니다. 되돌리기/다시 실행과 원본 복원도 사용할 수 있습니다. 원본 복원은 현재 캐릭터 리그에 적용되며 되돌리기로 취소할 수 있습니다.

## 내보낸 데이터 적용

JSON은 스크린샷이 아닌 실제 리그 데이터입니다. `format: doragami-rig-edits`, `version: 1` 아래에 캐릭터별 `rig.json` 내용과 공통 장비 정의가 저장됩니다. 개별 파일에도 공통 장비 정의가 포함됩니다. `preview`, `activeCharacter`, `completed`는 편집기 재개용으로, 게임의 기본 장착을 강제하지 않습니다. 이미지 원본은 저장소의 기존 파일을 사용합니다.

```sh
python3 scripts/apply_rig_edits.py exported.json --check
python3 scripts/apply_rig_edits.py exported.json
node --test tests/*.test.mjs
```

적용 도구는 등록된 캐릭터/장비 경로만 사용하고, 전체 입력 검증 후 리그와 장비 JSON을 씁니다. 변경 내역을 검토해 커밋·푸시합니다. `register_assets.py`는 원본 파츠에서 리그를 다시 생성하므로 수동 편집본을 적용한 뒤 재실행하면 덮어씁니다. 편집 JSON을 보관하고 필요하면 재적용합니다.

묶음 조정은 기존 애니메이션 transform 뒤에 `editorAdjustment` 표시가 있는 translate/rotate/scale을 추가합니다. 엔진이 이 transform을 실제 게임에서도 사용합니다. 손 파츠를 회전하면 장착점도 회전을 따라가며, 파츠 피벗을 바꾸면 기존 팔 애니메이션과 양손 자세의 피벗도 갱신됩니다. 손잡이와 장비 오프셋도 내보냅니다.

검증: `tests/rig-editor.test.mjs`, `BASE_URL=http://127.0.0.1:8008 python3 tests/rig-editor-browser.py`. 다운로드·재입력·임시 저장·회전축 위치 유지·모바일 터치·양손 장착을 확인합니다.

## 적용된 수동 조정과 장착점

`doragami-all-rig-edits-2.json`의 8종 조정값을 반영했습니다. 얼굴·머리장식·몸통·손·다리 파츠의 위치·크기·회전은 업로드 값 그대로 유지합니다. 검·방패·책·활의 크기를 줄이고, 새싹 지팡이와 마법봉의 길이를 조정했습니다. 깃대의 손잡이는 기둥에, 활은 감긴 손잡이에 연결하며 마법봉의 보조 손잡이도 실제 막대 위에 놓습니다. 새 몸통 위치에 맞춰 클로버마법사의 보행 시 다리는 상체의 수직 움직임을 따라갑니다.

장착점의 선택적 `rotation`은 손바닥 위치를 유지하면서 장비의 기준 방향만 보정합니다. 파츠의 정적 회전 뒤에 적용되고 팔 애니메이션은 계속 따라갑니다. 새 장비나 캐릭터의 보정은 엔진 분기 대신 리그의 `sockets`와 장비 설정에 기록합니다.

장비의 선택적 `socketMirrors: {left: true, right: false}`는 손잡이를 고정한 채 장비를 손별로 반전합니다. 깃발이 든 손의 바깥쪽으로 펼쳐지도록 사용하며 양손의 보조 손잡이 계산에도 같은 반전이 적용됩니다. 깃발기수의 연구실 미리보기는 펼쳐진 깃발이 잘리지 않도록 표시 배율을 조정합니다. 전장 크기는 유지합니다.

추가 검증: `BASE_URL=http://127.0.0.1:8010 python3 tests/equipment-grips-browser.py`. 실제 장비 이미지에서 주·보조 손잡이 좌표가 투명 영역을 벗어나지 않는지 검사합니다. 최신 맨손·권장 장착 렌더링은 `rig-hand-equipment-review.jpg`에 보관합니다.

왼쪽을 바라볼 때 화면 왼쪽에 보이는 오른팔은 리그의 `leftArm`/`hand_back`입니다. 깃발기수를 제외하면 이 묶음은 몸통 바로 뒤에 그립니다. 깃발기수는 몸통 앞 순서를 유지합니다. 방패와 책은 장비의 `drawLayer: foreground`로 캐릭터 파츠보다 앞에 그리며, 캐릭터 종류나 장착 손을 바꿔도 이 예외가 유지됩니다. 손잡이 행렬과 애니메이션은 기존 손 연결을 따릅니다.

개나리용사·새싹힐러는 숨김 처리해 현재 편집 목록과 전체 내보내기에는 새 캐릭터 6종만 포함합니다. 예전 8종 JSON과 임시 저장은 계속 불러올 수 있으며, 마지막 선택이 숨긴 캐릭터라면 표시 가능한 캐릭터에서 재개합니다.

이전 임시 저장은 예전 좌우 파츠 경로를 담고 있을 수 있습니다. 최신 교정 JSON을 불러오거나 원본에서 시작하면 현재 리그로 편집할 수 있습니다.

궁수와 클로버마법사는 왼손 장착 시 별도 `slotPoses.left.equipped` 자세로 팔을 들어 올립니다. 왼손의 무기 방향은 `socketMirrors`와 `socketRotations`로 바깥쪽을 향하며, 오른손 설정과 맨손 파츠는 유지합니다. `left-hand-grips.jpg`에서 실제 왼손 장착 결과를 확인할 수 있습니다.

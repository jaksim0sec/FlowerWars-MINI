# 전술 확장 기반

소대 구상은 상위 지휘 계층의 참고 자료로 사용했습니다. 이번 구현은 기존 이동/교전 기반 개선이며 소대 선택·횡대/종대 명령·회복·소집 UI는 추가하지 않습니다. 골든개나리병(기수)의 `capabilities: ["rally"]`는 향후 소집 역할을 나타내는 데이터입니다. 개별 소환/조작과 독립 리그를 유지합니다.

## 공정한 이동

이동 결정 주기마다 모든 개체가 현재 점유와 기존 예약을 기준으로 다음 이동 의도를 제출합니다. 칸별 경합은 오래 기다린 개체를 먼저 처리하고 동률은 시드·개체의 중립 우선순위·결정 주기로 계산합니다. 작은 ID나 A/B 이름을 우선하지 않습니다. 승자를 결정한 다음 예약을 일괄 실행합니다. 이미 진행 중인 출발/도착 칸 보호는 그대로 유지해 교환 충돌을 막습니다. 도중 조건 훅이 개체를 피격/사망 상태로 바꾸거나 전장을 초기화하면 오래된 의도는 실행하지 않습니다.

상위 지휘 계층은 `board.batchCommands(() => ids.forEach(id => board.move(id,x,y)))`로 같은 시점의 명령을 제출할 수 있습니다. 테스트 병력도 일괄 명령을 사용합니다. 기존 단독 수동 명령은 즉시 반응합니다. 미래 소대는 멤버 ID와 진형별 목표 칸을 관리하는 외부 계층으로 이 API를 호출하면 됩니다. 동일 목적지 자동 분산은 구현하지 않으며 주변 빈칸 배정은 향후 지휘 계층의 책임입니다.

테스트 메뉴에 재현 시드와 좌우 교환을 추가했습니다. 좌우 교환은 유닛·목적지·장애물·탐색 방향·통행 기준을 함께 반전합니다. 비전투 대규모 이동의 통행 행/열 분리는 유지하며 자동 교전 중에는 전진 경로를 단순화해 상대를 지나치도록 차선을 강요하지 않습니다. 시드는 고정된 편향을 재현/비교하기 위한 것으로 승률 50%를 강제하지 않습니다. 3개 시드의 32인 진형을 20초씩 비교해 진영 이름 교환과 좌우 반전 후 개체별 결과가 일치함을 확인했습니다.

## 원거리 탐색

근접은 기존 주변 타일 조회를 사용합니다. 사거리 3 이상은 8×8칸 공간 버킷으로 후보를 좁힙니다. 인덱스에는 현재 칸과 예약된 도착 칸이 들어가며 생성/한 걸음 시작/도착/사망/초기화 때만 갱신합니다. 매 프레임 전 개체를 다시 색인하지 않습니다. 실제 보간 위치로 사거리를 검사합니다.

유효한 적은 유지하며 사망·사거리 이탈·차폐 시 재탐색합니다. 재탐색 시점은 개체별 위상으로 분산합니다(기본 약0.24초). 동거리 후보는 시드 우선순위를 사용합니다. `lineOfSight:true`이면 범위로 후보를 줄인 뒤 장애물 시야를 확인하고, 명중 시에도 다시 검사합니다. 궁수는 사거리4/선호거리3, 새싹힐러는 사거리3/선호거리2를 테스트 데이터에 적용했습니다. 별도 투사체 그림이나 탄도는 추가하지 않았습니다.

적이 선호거리보다 가까우면 준비된 개체는 이웃 최대4칸에서 사거리 안의 후퇴 칸을 고릅니다. 경로 전체를 다시 구하지 않습니다. 같은 진입 조건 훅과 예약 중재를 거치고 명시적 수동 공격은 우선합니다. 공간이 없으면 공격하며, 무제한 적 추격/도주 AI는 없습니다.

## 이동 개성

`testMovement`의 `stepTime`, `waitBeforeDetour`, `yieldAfter`로 실제 한 걸음 시간·우회 전 대기·옆 대피 지연을 관리합니다. 방패병은 느리고 기다리는 편, 개나리 기사는 빠르게 우회, 기수/보조는 중간 속도입니다. 무기 데이터의 `movement.stepMultiplier`는 테스트 배치 시 합성합니다. 공통 거리장과 경로 캐시는 그대로 공유합니다. 중립 기본 시연의 이동 시간0.34초는 유지합니다. 부상 자체가 능력치를 낮추지는 않습니다.

## 검증과 한계

- 전체 Node 테스트: `node --test --test-isolation=none tests/*.test.mjs`.
- `tests/tactical-foundation.test.mjs`: 제출 순서/시드/좌우·진영 교환, 속도, 거리 유지, 조건 훅, 초기화.
- `tests/ranged-search.test.mjs`: 1000개체 중 좁은 후보 조회, 목표 유지/분산, 시야, 인덱스 생명주기와 명중 재검사.
- `scripts/benchmark_navigation.mjs`: 1000개체 전원90초 모의 진행 내 도착, 점유/예약 충돌0. 모델 update p95 약0.506ms.
- `scripts/benchmark_combat.mjs`: 1000개체 12초 모의 교전, 점유/예약 충돌0. 모델 update p95 약0.375ms. 브라우저 FPS/GPU/모바일 성능 수치가 아닙니다.

막힌 외길이나 완전히 둘러싸인 목표는 여전히 대기할 수 있습니다. 복잡한 전장을 위한 완전 최적 다중 개체 경로 해법은 아닙니다. 밀집 구역의 대규모 원거리 병력이 모두 탐색하면 후보 수에 따른 비용은 남습니다. 탐색/위치/장비 역할은 데이터와 독립 모듈로 분리해 향후 소대 지휘를 얹을 수 있도록 했습니다. 화면 밖에서도 이동·탐색·교전·사망 데이터는 처리하며 그리기만 생략합니다.

# 도라가미 원화 6종 모듈형 캐릭터 에셋

GitHub `assets/units/gynari-warrior/rig.json` v6 구조를 기준으로 독립화한 원화 6종입니다.

- 일러스트: 이전에 확정한 1·3·4·5·8·9번 원화를 픽셀 분할. 원화 채색·선·표정·방향은 재생성/변형하지 않음.
- 공통 리그: 1000×1500 아트보드, 발 앵커 [505,1228], 3/4 시점, `hand_back`, `hand_front`, `head`, `head_deco`, `body`, `leg_back`, `leg_front`, `shadow`.
- 손목: 실제 소매/팔은 `body`에, 손목/손은 손 파츠에. 손 소켓은 왼쪽/오른쪽 각각 독립. 방패기사의 가려진 손은 동일 그림의 반대편 손을 복제한 최소 보충 파츠.
- 무기: 검/활/꽃 지팡이/책/깃발/방패는 `assets/equipment/weapons/`에 별도 저장. 권장 장비만 있고 빌트인 장비는 없음.
- 가방/화살통/망토: 원화에서 추출한 교체 가능한 단독 이미지로 `assets/equipment/accessories/`에 저장. 기본 원형 보존을 위해 리그 노드에서 배치됨.
- `source-reference.png`: 원래 일체형 원화 보존. 파츠 조립/수정 시 비교 기준.
- `rig.json`: 캐릭터별 상대 크기·위치·앵커/피벗/양손 소켓/애니메이션 노드 정의. 무기 파지점은 equipment catalog에 정의.
- `roster-manifest-additions.json`: 게임 기본 manifest에 병합할 캐릭터/장비 신규 항목.

**주의**: 본 작업은 원본 픽셀 보존을 우선해 보이는 파츠를 분할했습니다. 방패/책/머리 장식에 가려진 뒤쪽 그림은 원래 그림에 존재하지 않으므로, 완전한 장비 해제나 큰 관절 회전 시 가림이 드러날 수 있습니다. 임의로 새 그림체를 생성하지 않았습니다. 리깅과 손 위치는 후속 시각 조정 가능하게 저장돼 있습니다.

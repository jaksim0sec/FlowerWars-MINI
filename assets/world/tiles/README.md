# 도라가미 타일 에셋 (2종)

| 파일 | 용도 |
| --- | --- |
| `grass.webp` | 잔디 타일, 투명 배경, 256 × 144 |
| `soil.webp` | 흙 타일, 투명 배경, 256 × 144 |
| `tiles.json` | 2:1 쿼터뷰 투영 좌표와 에셋 매핑 |

- 위 시안에서 **타일 윗면만 추출**해 같은 크기와 꼭짓점으로 맞췄다. 마름모 밖은 투명이다.
- 외곽 측면/벽돌/기둥/장식은 나중에 별도 월드 오브젝트로 처리해야 한다. 타일마다 벽면을 그리면 내부 경계가 겹친다.
- 실제 투영: `left = originX + (col-row)*128`, `top = originY + (col+row)*72` (256×144 기준).
- 타일 기울기 `atan(1/2) ≈ 26.565°`. 이는 화면 투영 각도이지 실제 3D 카메라 렌더링 설정이 아니다.
- PNG 소스는 작업 ZIP에 포함했다. GitHub에는 가벼운 WebP를 등록한다.

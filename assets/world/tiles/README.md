# 도라가미 전장 타일 2종

| 파일 | 용도 |
| --- | --- |
| `grass.webp` | 개나리 진영의 연두 잔디 표면 |
| `soil.webp` | 황토색 흙 표면 |
| `tiles.json` | 타일 투영 크기 및 좌표 매핑 |

- 컨셉아트에서 윗면만 분리한 **투명 배경 WebP**, 공통 크기 **256×144**.
- 실제 그림 비율은 **16:9**이고 화면상 모서리 기울기는 약 **±29.36°**. 통상적인 2:1 등각투영(±26.565°)과 다르므로 두 값을 혼용하지 않는다.
- 보드 위치: `left = originX + (col-row)*128`, `top = originY + (col+row)*72` (원본 크기 기준).
- 실제 3D 카메라의 방위각/고도는 2D 컨셉아트 한 장으로 확정할 수 없다.
- 이미지에 측면 벽을 포함하지 않는다. 외곽 돌받침과 잔디 장식은 별도 월드 오브젝트로 추가한다.
- 표면 반복 배치 시 투명 경계에서 픽셀 틈이 보이면 렌더러에서 0.5~1px 오버랩을 적용한다.
